# 狼人杀面杀助手

不用法官的线下狼人杀工具。大家用手机扫码进房间、按座位坐下，手机发牌；
房主的手机外放语音主持夜晚，每个角色在自己手机上操作。

只用 Python 标准库，不需要安装任何依赖。

## 运行

```bash
python3 server.py
```

启动后终端会打印两个地址：

- `http://localhost:3210` —— 在这台电脑上打开
- `http://192.168.x.x:3210` —— 手机打开（手机要和电脑连同一个 Wi-Fi）

房主创建房间后，页面上的二维码已经是局域网地址，其他人直接扫就行。
换端口：`PORT=8080 python3 server.py`。

> 学校、公司的 Wi-Fi 常常不允许设备之间互相访问。如果手机打不开，
> 让电脑和手机都连同一个手机热点，或者部署到公网（见最后一节）。

## 一局的流程

1. 房主创建房间，点「改板子」：套用常规板子，或者自己给每个身份设张数。
2. 其他人扫码，填昵称，点自己实际坐的座位号。
3. 坐满后房主点「发牌」，每人按住屏幕看身份。
4. 房主点「天黑请闭眼」，把手机放在桌子中间。之后夜晚全自动。
5. 天亮后先竞选警长（可关），再公布昨夜倒牌的人。
6. 发言在线下进行，房主点「开始投票」，每人在手机上投票。
7. 重复 4-6，直到一方获胜。结束后全员亮牌，并显示每晚发生了什么。

大家一起操作的环节（看身份、上警、退水、投票、出局确认），每个座位旁边会标出「做完了」还是「还没做」，
一眼能看出在等谁。夜晚不显示，否则等于告诉所有人谁是什么身份。

## 板子

常规板子（18 套）：

| 人数 | 板子 |
|---|---|
| 6 / 7 / 9 / 10 | 预女、预女猎、预女猎、预女猎守 |
| 12 | 预女猎白、预女猎守、狼王守卫、白狼王守卫、白狼王骑士、狼美人骑士 |
| 12 | 机械狼通灵师、石像鬼守墓人、梦魇守卫、恶灵骑士、血月猎魔 |
| 12 | 狼王摄梦人、狼王魔术师、丘比特 |

自定义：22 个身份都可以自由加减，4 到 18 人。狼人和村民可以多张，其它身份最多一张。

- 狼人阵营：狼人、狼王、白狼王、狼美人、梦魇、血月使徒、恶灵骑士、石像鬼、机械狼
- 神职：预言家、女巫、猎人、守卫、白痴、骑士、通灵师、守墓人、摄梦人、魔术师、猎魔人、丘比特
- 平民：村民

没有做的：盗贼、野孩子、混血儿、熊、乌鸦、禁言长老、隐狼等。

## 夜晚顺序和语音同步

顺序固定（板子里没有的角色不会叫）：

**丘比特 → 情侣确认 →** 梦魇 → 魔术师 → 摄梦人 → 守卫 → 机械狼 → 狼人 → 狼美人 → 石像鬼 → 女巫 → 预言家 → 通灵师 **→ 守墓人 → 猎魔人**

丘比特和情侣确认只在第一夜；守墓人和猎魔人从第二夜开始。
原则是：会改变别人技能落点的先行动，要知道刀口的女巫在狼人之后，只拿信息的角色最后。

语音和手机操作是锁在一起的，不靠计时：

- 「X 请睁眼」播完，X 的手机才出现操作界面；
- X 在手机上操作完，才播「X 请闭眼」；
- 「X 请闭眼」播完、停顿两秒，才轮到下一个角色。

某个角色已经出局、被梦魇恐惧或被血月封印时，语音照常叫他，流程和时长看不出区别。
房主手机离线或刷新页面时游戏会暂停等它回来，不会跳过语音；
房主掉线时，其他任何人可以点「用我的手机播报」接管。

## 警长竞选（上警）

第一天天亮后、公布死讯之前进行。昨夜倒牌的人此时还不知道自己出局，照常参加。

1. **上警**：所有人在手机上同时选「上警 / 不上警」，全部选完才公布名单。
2. **竞选发言**：手机随机定一个起始位置和方向，上警的人按顺序发言。
3. **退水**：房主点「进入退水环节」，警上的人同时选「退水 / 留在警上」。
4. **投票**：只有警下（一开始没上警）的人投票；上过警的人，包括退水的，这一轮都不投。
5. **平票 PK**：平票的人再发言一轮，然后警下和退水的人一起再投一次；再平票则警徽流失。
   一直留在警上但没进 PK 的人，PK 这一轮也不投。

特殊情况：

- 没人上警、所有人都退水、警下全部弃票：警徽流失。
- 退水后只剩一人：直接当选。
- 所有人都上警且没人退水：没有警下能投票，警徽流失。
- 竞选发言、退水、PK 阶段狼人可以自爆：第一天被打断则推迟到第二天重新竞选；第二天再被打断则警徽流失。

警长的权力：放逐投票算 1.5 票；每天决定从自己哪一侧开始发言，自己最后发言；
出局时把警徽移交给一名活着的玩家，或者撕掉。

## 规则细节

| 项目 | 做法 |
|---|---|
| 狼人 | 所有握刀的狼选中同一个目标后，任意一人确认；可以空刀；可以自爆 |
| 狼王 | 被刀、被放逐、被枪带走时可以开枪；被毒、自爆、殉情、决斗出局时不能 |
| 白狼王 | 自爆时可以带走一人 |
| 狼美人 | 每晚可魅惑一人（不能连续同一人）；她出局时最近被魅惑的人殉情，被骑士决斗出局除外；不能自爆、不能被自刀 |
| 梦魇 | 每晚最先行动，恐惧一人使其当晚技能失效（不能连续同一人）；恐惧到狼人则当晚不能刀；第一夜恐惧前不认识队友；被恐惧的猎人当晚倒牌不能开枪 |
| 血月使徒 | 自爆后的当晚神职技能全部封印；作为最后一狼被放逐时，活到下一个天亮再出局 |
| 恶灵骑士 | 夜里不会死；被预言家 / 通灵师查验或被女巫下毒时，对方次日出局（整局一次）；不能自爆、不能被自刀 |
| 石像鬼 | 不和狼队友见面；每晚查验一人的具体身份；狼队友全部出局后握刀 |
| 机械狼 | 不和狼队友见面；整局学习一人一次（通灵师→查验，女巫→一瓶毒药，守卫→守护，猎人→开枪，狼人→一次双刀），学到的技能次日晚生效；学习后被查验显示成学到的身份；狼队友全部出局后握刀 |
| 女巫 | 同一晚只能用一瓶药；解药用掉后不再知道刀口；自救规则可选 |
| 守卫 | 不能连续两晚守同一人；同守同救仍然倒牌；挡不住毒 |
| 骑士 | 白天发言阶段整局一次决斗：对方是狼人则对方出局并立刻天黑，否则骑士出局 |
| 守墓人 | 从第二夜起，得知前一天被放逐的人是好人还是狼人 |
| 摄梦人 | 每晚必须选一人梦游，梦游者免疫狼刀和毒；连续两晚同一人则他死亡；摄梦人夜里死亡时梦游者一起死 |
| 魔术师 | 每晚可交换两个号码，当晚对其中一人的技能落到另一人身上；每个号码整局只能换一次 |
| 猎魔人 | 从第二夜起可狩猎一人：是狼人则对方出局，否则自己出局；免疫毒药 |
| 丘比特 | 第一夜连两人为情侣（可含自己），一人出局另一人殉情；一好一狼时，情侣和丘比特是第三方，其他人全部出局才算赢；殉情的猎人不能开枪 |
| 白痴 | 被放逐时翻牌免死，之后不能投票，也不能再被投 |
| 放逐投票 | 平票进入 PK，PK 台上的人不投票；再平票则无人出局 |
| 遗言 | 第一夜倒牌的人、被放逐的人、被枪带走的人有遗言（手机只提示，不计时） |
| 胜负 | 默认屠边（神或民死光狼人胜），可改屠城；多人同时出局时按行动顺序逐个结算 |

和传统法官流程不同的两点：

- **没有「猎人请睁眼」环节**。猎人出局时，手机直接告诉他能不能开枪。
- **每个出局的人都要在手机上点一下确认**。这样旁人无法从「谁在看手机」判断谁是猎人。

各平台说法不一、这里选了其中一种的地方：

- 狼美人夜里被毒死，被魅惑的人也殉情（有的平台不殉情）。
- 警上自爆是「推迟一天，再爆才流失」（有的规则是直接流失）。
- 警长 PK 投票时退水的人可以投（有的平台只让警下投）。
- 机械狼可以在任意一晚学习（有的规则限定第一夜）。

## 目录

```

game.py            游戏引擎：夜晚流程、结算、警长竞选

public/art/        界面素材：边框、座位牌、记号、月亮、药瓶、卡背（SVG）
public/fonts/      界面用的手写风字体子集

Dockerfile         给支持 Docker 的托管平台用
```

## 测试

```bash
python3 -m unittest discover -s tests
```

70 个测试。除了逐条规则，还包含约 500 局随机对局（每套常规板子各 24 局，
外加把所有角色混在一起的 80 局），检查每一局都能打完、每一夜语音顺序正确、
手机上出现的操作界面始终和语音叫到的环节一致。

一个人试玩：浏览器里创建房间后运行

```bash
python3 tools/bots.py 房间号
```

机器人会补满座位并自动行动。

## 换语音

台词在 `clips.py`。改完后在 Mac 上运行：

```bash
python3 tools/gen_audio.py
```

默认用系统自带的「婷婷」。也可以自己录音，用同名 `.m4a` 文件替换 `public/audio/` 里的文件。

## 画风和素材

界面是手绘风，但尽量简单：平涂的底色、手写体的字、手画的一圈线，没有别的装饰。
颜色只有旧纸、墨和骨白，加少量芥末黄（主要按钮）、血红（危险 / 狼人）、苔绿（做完了）。
底色跟着阶段走：平时是深褐色，夜晚最暗，白天是旧纸色。
角色头像是大头小身子、圆白眼、黑眼圈的线稿，只在身份卡、改板子和结束亮牌时出现。

所有图都是脚本画的，没有用到外部图片：

```bash
python3 tools/sketch/build.py            # 重画 22 个头像和全部界面素材
python3 tools/sketch/build.py --sheet    # 另外生成 public/_sheet.html，一页看完所有素材
```

- `tools/sketch/rough.py`：那支「笔」，把几何形状画成手绘线条、平涂色块和排线。
- `tools/sketch/portraits.py`：22 个角色。人和狼各有一副共用底稿，每个角色加帽子、头发、道具。
  改某个角色就改它对应的那个函数。
- `tools/sketch/ui_art.py`：界面素材（边框、座位牌、记号、月亮、药瓶、卡背）。边框是九宫格图，给 CSS 的 `border-image` 用。

字体是站酷小薇体（ZCOOL XiaoWei，SIL OFL 许可）的子集，只包含界面里出现过的字，约 180 KB。
改了文案、出现新字以后重新下载一次：

```bash
python3 tools/fonts/fetch.py
```

玩家昵称里子集没有的字会自动用系统宋体显示。

## 背景音乐

背景音乐只在首页、大厅和结束页播放，开局后自动停；房主手机播报语音（包括试音和宣布胜负）时
背景音乐会先停下，播完再继续。背景音乐的开关只管背景音乐，关掉它不影响语音播报；
首页左上角和菜单里可以关掉。默认是浏览器现场合成的一段夜晚小调；
想换成自己的曲子，把文件放到 `public/audio/bgm.m4a`，会自动优先播放它。

## 部署到公网

这个程序需要一个一直运行的后台进程来保存房间状态，所以**不能放在 GitHub Pages**
这类只能放静态网页的地方。GitHub 用来存代码，运行要交给能跑 Python 的平台。

### 方案一：GitHub 存代码 + Render 免费运行

1. 把这个文件夹推到一个 GitHub 仓库。
2. 在 render.com 用 GitHub 账号登录，New → Blueprint，选这个仓库。
   仓库里的 `render.yaml` 已经写好了配置（免费档）。
3. 部署完成后得到一个 `https://xxx.onrender.com` 地址，发给朋友或让他们扫房间二维码。

免费档的限制：服务器 15 分钟收不到新请求就休眠，下次打开要等大约一分钟唤醒；
休眠或重启后，进行中的房间会丢失（房间数据在内存里）。

为了不在局中休眠，页面带了保活：只要有一台手机开着房间页面，它每 4 分钟会自动发一个很小的请求。
所有人都关掉页面或锁屏超过 15 分钟，房间仍然会丢。

### 方案二：临时把本机服务映射到公网

电脑上先运行 `python3 server.py`，另开一个终端：

```bash
ssh -R 80:localhost:3210 nokey@localhost.run
```

它会打印一个临时的 `https://...` 地址，用这个地址打开页面再建房间，二维码就是公网地址。
不需要注册账号，但电脑要一直开着，地址每次都会变。

### 其它平台

- 只能跑一个实例（房间数据在内存里）。
- 不能用无状态函数类的平台（需要保持长连接）。
- 前面有反向代理时，要关闭对 `/api/events` 的响应缓冲。
- 有 `Dockerfile`，支持 Docker 的平台可以直接用。
- 国内访问需要考虑域名备案。
